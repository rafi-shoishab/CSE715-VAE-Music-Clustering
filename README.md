# Music Representation Learning using Variational Autoencoder

## Course
CSE715 – Neural Network & Fuzzy System

## Project Description
This project learns latent representations of music using a Variational Autoencoder (VAE) and performs clustering in latent space.

## Pipeline
Audio → MFCC → VAE → Latent Space → KMeans → Evaluation

## Dataset
GTZAN Genre Dataset

## Methods
- MFCC Feature Extraction
- Variational Autoencoder
- KMeans Clustering
- t-SNE Visualization

## Metrics
- Silhouette Score
- Calinski-Harabasz Index

## How to Run
Open the notebook in Google Colab and run all cells sequentially.
